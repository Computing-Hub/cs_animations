Insertion sort lifts each key out, shifts bigger items right and drops it into the gap; green shows the part that is sorted so far. Quick sort draws a tree: each range splits into values less than the pivot, the pivot itself, and values greater than or equal to it. A bad pivot (try First item on an already sorted array) makes a tall, thin tree and many more comparisons. Merge sort first divides the list down to single items, then merges pairs back together in order.
