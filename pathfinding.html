SHORTEST PATH — DIJKSTRA & A*

Find the shortest path from A to H on a random weighted graph. Each Step does one thing: visit (lock in) a node, or check one of its neighbours and update its cost if the new route is cheaper. The table gets one row per visit. Dijkstra finds the shortest path from A to every node, so it keeps going until all of them are locked in, always choosing the unvisited node with the lowest cost so far. A* is aimed at one goal: it adds a heuristic (the straight-line distance to H) and stops as soon as H is locked in, so it usually locks in fewer nodes.
