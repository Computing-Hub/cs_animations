Little Man FDE Cycle

The Little Man Computer

Load an assembly program, then step through the Fetch, Decode, Execute cycle. Follow the Little Man as he moves values between the registers, the ALU and memory along the address and data buses.

  1. F
    FetchCopy the next instruction from memory into the CPU, using the PC, MAR, MDR and both buses.
  2. D
    DecodeSplit the instruction in the CIR into its opcode and operand and work out what it means.
  3. E
    ExecuteCarry out the instruction using the registers, the ALU and memory. Then the cycle repeats.
